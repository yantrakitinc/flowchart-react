# FlowChart React

A React component for visualizing user flows, decision trees, and process diagrams with automatic layout, path detection, and interactive features.

## What It Does

1. **Automatic Layout** - Define your nodes and edges, and the component automatically positions them in a readable left-to-right flow
2. **Path Detection** - Automatically detects all possible paths from start to end nodes
3. **Path Selection** - Users can select a specific path to highlight, dimming all other nodes and edges
4. **Clickable Nodes** - Every node is clickable with customizable click handlers
5. **Zoom & Pan** - Built-in zoom and pan controls for navigating large flowcharts
6. **Active Node Highlighting** - Highlight the current/active node in your flow

## How Path Selection Works

1. The component analyzes your flow and detects all unique paths from start nodes to end nodes
2. A path drawer (positioned top, bottom, left, or right) displays all detected paths
3. Each path shows its type (happy, error, warning) based on the edges it contains
4. Clicking a path highlights only the nodes and edges in that path
5. All other nodes and edges are dimmed for clarity
6. Click the selected path again (or use the clear button) to show all nodes

## How Node Clicking Works

1. Every node in the flowchart is clickable
2. Pass an `onNodeClick` callback to receive click events
3. The callback receives the full node object with id, label, type, and description
4. Use this to show details, navigate, or trigger actions based on the clicked node
5. Combine with `activeNodeId` to visually highlight the clicked node

## Quick Start

```tsx
import { FlowChart } from '@yantrakit/flowchart-react';
import '@yantrakit/flowchart-react/styles';

const flow = {
  id: 'my-flow',
  name: 'My Flow',
  nodes: [
    { id: 'start', label: 'Start', type: 'start' },
    { id: 'process', label: 'Process', type: 'action' },
    { id: 'end', label: 'End', type: 'end' },
  ],
  edges: [
    { from: 'start', to: 'process', type: 'happy' },
    { from: 'process', to: 'end', type: 'happy' },
  ],
};

function App() {
  return (
    <div style={{ height: '500px' }}>
      <FlowChart
        flow={flow}
        onNodeClick={(node) => console.log('Clicked:', node.label)}
      />
    </div>
  );
}
```
