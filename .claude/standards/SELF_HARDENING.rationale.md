# SELF_HARDENING — why

## Why files, not memory

The model cannot carry learning across sessions; artifacts can. A lesson written
with a terminal citation changes every future session's behavior (injection),
every future commit (fixtures), and every future rule reading (standard edits).

## Why every lesson must terminate

An unterminated lesson is a war story; a terminated one is a reflex. The enum
forces each entry to become a gate, a rule change, or an explicit open item that
haunts every session start until closed.

## Why fixtures over vigilance

The weekend proved gates regress exactly like product code. A fixture per learned
failure makes regression mechanically impossible — the corpus only grows.

## Why proposals queue for the user

Standards-change authority is the one thing never delegated. The miner turns
patterns into suggestions; ratification stays human.
