# FlowChart React

**A Mermaid-like, AI-first React flowchart.** Describe a diagram in a compact text language (or a
plain data object) and get a fully interactive, auto-laid-out flowchart where **every node is a real
React component** — rendered on [React Flow](https://reactflow.dev).

```tsx
import { FlowChart } from '@yantrakit/flowchart-react';
import '@yantrakit/flowchart-react/styles';

<FlowChart height={480} chart={`flowchart TD
  start([Order placed]) --> pay{Payment OK?}
  pay -->|yes| ship[Ship order]
  pay ==>|no| fail[Payment failed]:::error
  ship --> done([Delivered])
  fail --> done`} />
```

---

## What is this package?

Three kinds of tools exist in this space, and each forces a trade-off. This package removes it:

| | Authoring | Interactivity | Auto-layout |
|---|---|---|---|
| **Mermaid** | ✅ text (great) | ❌ static SVG | ✅ |
| **React Flow** | ❌ hand-built objects + positions | ✅ excellent | ❌ (you position nodes) |
| **@yantrakit/flowchart-react** | ✅ **text _or_ object** | ✅ **React Flow under the hood** | ✅ **dagre / ELK** |

You write **diagram-as-code** like Mermaid, but you get **React-Flow-grade interactivity** — clickable
custom nodes, drag, zoom, pan, minimap — plus something neither gives you: **semantic path detection**
(automatically find and color the happy / warning / error routes through a graph).

## Why "AI-first"?

Everything an agent needs is a first-class, no-React surface:

- **Text in, text out.** `parseFlowchart(text)` → graph object; `serializeFlowchart(graph)` → text. An
  agent (or an LLM) can read a diagram, mutate the object, and write valid diagram text back.
- **A published JSON Schema** for the graph shape (`@yantrakit/flowchart-react/schema`) so a tool can
  validate a diagram without importing any TypeScript.
- **Stable selectors** on every rendered element (`data-testid`, `data-node-id`, `data-agent-action`)
  so an agent or a test can drive the UI deterministically.

## How it works — five small layers

```
  text DSL ─▶  parse  ─▶  IR (graph)  ─▶  layout  ─▶  render (React Flow)
  "flowchart              the single       dagre or      custom nodes,
   TD ..."                source of        ELK; honors   edges, minimap,
                          truth            TD/LR/BT/RL   path drawer
   graph object ────────▶     │
                              └─▶  path model  ──▶  happy / warning / error
```

Only the render layer touches React. `parse`, `layout`, and the path model are pure TypeScript you can
use headless (Node scripts, build tools, agents).

## Node & edge vocabulary

**7 node types** — each has a shape + a status color:

| Type | Meaning | Shape |
|---|---|---|
| `start` / `end` | entry / exit | stadium (pill) |
| `action` | a step | rounded rectangle |
| `decision` | a branch | diamond-ish |
| `error` / `warning` / `link` | failure / caution / reference | rounded rectangle, status-colored |

**4 edge types** — the edge type colors any path that runs through it:

`happy` (green) · `warning` (amber, dotted) · `error` (red, thick) · `default` (grey)
